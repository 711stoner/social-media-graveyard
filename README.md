# 社媒坟场 / Social Media Graveyard

“社媒坟场”是个人社交媒体备份工具的统一入口，也是一个独立的社媒墓碑项目。

用户可以：
- 使用 X、Threads、微博、豆瓣、知乎、小红书等个人备份插件保存自己的内容；
- 不安装任何插件，直接为自己的社交账号建立墓碑；
- 在用户明确公开后，以墓碑形式保留平台、账号、头像、时间与可选墓志铭；
- 后续在墓碑上使用献花、点蜡烛等纪念互动。

正式网站：https://711stoner.github.io/social-media-graveyard/
